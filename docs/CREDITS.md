# Credits and asset provenance

**Creator:** NXR / [@nxrskyaa](https://x.com/nxrskyaa)

**Built for:** Dlicom AI Game Jam, September 22–October 5, 2026.

## Game

Concept, art direction, implementation and iteration: NXR with Codex assistance. World geometry, courier hulls, obstacle mechanics, camera, lighting and gameplay effects are authored in code. References informed composition, material contrast and game UI rhythm; their game code or character artwork is not shipped here.

DILI's contextual guidance runs from local rules. The game uses AI-assisted development; it does not require an external AI API while playing.

## Brand

Dlicom's mark and DILI remain their owners' brand/character. This jam project is not an official Dlicom product. The illustration and procedural model should not be described as official source models or exact 3D copies.

## Audio and film

**Afterglow Dispatch** is an original score generated by the project's offline synthesis script: electric piano, bass, breakbeats and melodic phrases, with no sampled commercial music. Game sound effects are synthesized. The launch film uses an edited segment of this score and original synthesized transition/engine cues.

The film is edited with Remotion. Footage comes from the game's live renderer with scripted controls and ordinary gameplay rules. Audio and editorial overlays are added afterward.

## Dependencies

Next.js, React, Three.js, React Three Fiber, Drei, Zustand and Tailwind CSS power the game. Remotion powers the separate video project. Dependency licenses remain their respective authors' licenses.
